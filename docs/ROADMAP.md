# Portfolio3D roadmap

## Current experiment

Build a room-style interactive portfolio inspired by the reference showcase at `https://shahbaj-sheikh.vercel.app/`. The room uses procedural geometry rather than a downloaded model so the project remains small, editable, and easy to test on a phone.

## Next increments

1. Validate camera feel and frame rate on Jazz's phone.
2. Replace procedural poster geometry with optional authored GLTF props only if they improve navigation without hurting load time.
3. Add a focused case-study view for selected projects while keeping the complete archive accessible.
4. Add a production preview and compare desktop/mobile input behavior.
